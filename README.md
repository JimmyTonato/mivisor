# Mi Visor

App Android que abre el link que haya en `config.json`.

- **Cambiar la página:** edita `config.json` en GitHub y guarda. En la app, pulsa el botón ⟳.
- **Descargar la APK:** pestaña *Releases* → última versión → `MiVisor.apk`.
- La APK se compila sola al subir cambios de código (pestaña *Actions*).
